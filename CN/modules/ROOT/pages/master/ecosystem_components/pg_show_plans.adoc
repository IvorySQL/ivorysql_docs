= pg_show_plans

== 概述

pg_show_plans 是一个 PostgreSQL 扩展，用于显示当前所有正在运行的 SQL 语句的查询计划。查询计划可以以多种格式展示，包括 `TEXT`、`JSON` 和 `YAML`。

NOTE: 该扩展在共享内存中创建哈希表。哈希表大小不可动态调整——一旦填满，将无法添加新的查询计划记录。

== 安装

[TIP]
源码安装环境为 Ubuntu 24.04（x86_64），环境中已安装 IvorySQL 5 及以上版本，安装路径为 `/usr/ivory-5`。

=== 源码安装

在开始之前，请确保 `pg_config` 可在 PATH 中访问。

[source,bash]
----
git clone https://github.com/cybertec-postgresql/pg_show_plans.git
cd pg_show_plans

make PG_CONFIG=/usr/ivory-5/bin/pg_config
make PG_CONFIG=/usr/ivory-5/bin/pg_config install
----

=== 在 Windows 上从源码构建

[TIP]
本节在 Windows 11 上验证，编译器为 Visual Studio 2022 Build Tools（MSVC 19.44）。IvorySQL 的 Windows 移植仍在审查中，验证使用的 IvorySQL 是 https://github.com/jiabin777on-hue/IvorySQL/tree/win/reference[Windows 测试基线] 的提交 `947b50e1`，即 master 加上尚未合并的 Windows 移植 PR（IvorySQL #2321、#2332、#2333、#2485、#2530、#2811、#3418、#3419、#3420、#3421）。

在 “Developer PowerShell for VS 2022” 中编译并安装 IvorySQL。需要 Git、Strawberry Perl、winflexbison 和 Meson（含 Ninja）在 `PATH` 中。验证时另外加了 `-Dcassert=true -Dtap_tests=enabled` 以运行测试。

[source,powershell]
----
git clone --branch win/reference https://github.com/jiabin777on-hue/IvorySQL.git
Set-Location IvorySQL
git checkout 947b50e1
meson setup build --prefix=C:\ivorysql -Dauto_features=disabled -Duuid=none
ninja -C build
meson install -C build
Set-Location ..
----

Windows 上没有 PGXS，可以用 MSVC 的 `cl` 和 `link` 直接编译插件，并链接 IvorySQL 安装目录中的 `postgres.lib`。克隆时设置 `core.autocrlf=false`，避免测试数据文件被转换为 CRLF。

[source,powershell]
----
$IVY = 'C:\ivorysql'
$INC = "$IVY\include\postgresql\server"
$CFLAGS = @("/nologo", "/c", "/O2", "/MD", "/utf-8", "/std:c11", "/DWIN32", "/DWINDOWS",
    "/D__WINDOWS__", "/D__WIN32__", "/D_CRT_SECURE_NO_DEPRECATE", "/D_CRT_NONSTDC_NO_DEPRECATE",
    "/I.", "/I$INC\port\win32_msvc", "/I$INC\port\win32", "/I$INC", "/I$IVY\include")
git clone -c core.autocrlf=false https://github.com/cybertec-postgresql/pg_show_plans.git
Set-Location pg_show_plans
git checkout 92ecb21f8f23
# MSVC C2375: remove the declaration that lacks PGDLLEXPORT; PG_FUNCTION_INFO_V1 declares the function
(Get-Content pg_show_plans.c) | Where-Object { $_ -ne 'Datum pg_show_plans(PG_FUNCTION_ARGS);' } | Set-Content -Encoding ascii pg_show_plans.c
cl @CFLAGS pg_show_plans.c
link /nologo /DLL /OUT:pg_show_plans.dll pg_show_plans.obj "$IVY\lib\postgres.lib"
Copy-Item pg_show_plans.dll "$IVY\lib\postgresql\"
Copy-Item pg_show_plans.control, pg_show_plans--*.sql "$IVY\share\postgresql\extension\"
----

验证的版本为 pg_show_plans 2.1.8（提交 `92ecb21f8f23`）。

MSVC 会报 C2375（重定义；不同的链接）：源码在 `PG_FUNCTION_INFO_V1(pg_show_plans)` 之前另外写了一个不带 `PGDLLEXPORT` 的 `pg_show_plans` 声明。上面的命令删掉了这一行，`PG_FUNCTION_INFO_V1` 已经声明了该函数。这是插件本身的问题，在 PostgreSQL 上用 MSVC 编译也一样。

pg_show_plans 需要预加载。IvorySQL 在 `ivorysql.conf` 中默认设置了 `shared_preload_libraries = 'gb18030_2022, liboracle_parser, ivorysql_ora'`，要把 pg_show_plans **追加**到这个列表后面，例如 `shared_preload_libraries = 'gb18030_2022, liboracle_parser, ivorysql_ora, pg_show_plans'`。如果只写 `'pg_show_plans'`，会覆盖默认列表，Oracle 模式的连接会报 `liboracle_parser not found`。

验证结果：插件自带的回归测试 `pg_show_plans` 和 `formats` 在 PG 模式下全部通过（2/2）。在 Oracle 模式下（脚本中补上 `/` 后）结果与期望输出完全一致。插件自带的回归测试脚本按 PostgreSQL 的语法编写。Oracle 模式的 psql 要看到单独一行的 `/` 才会发送 `CREATE FUNCTION`（即使函数体用 `$$` 引用），所以要在 Oracle 模式下运行这些脚本，需要在每个 `CREATE FUNCTION` 语句后面加一行 `/`。

=== 配置 shared_preload_libraries

在 `ivorysql.conf` 中将 `pg_show_plans` 添加到 `shared_preload_libraries` 参数：

[source,conf]
----
shared_preload_libraries = 'liboracle_parser, ivorysql_ora, pg_show_plans'
----

重启 IvorySQL 实例使配置生效：

[source,bash]
----
pg_ctl restart -D data
----

=== 创建扩展

服务器重启后，连接到目标数据库并创建扩展：

[source,sql]
----
CREATE EXTENSION pg_show_plans;
----

== 使用方法

=== 查看当前查询计划

使用 `pg_show_plans` 视图，可以查看所有当前正在运行的 SQL 语句的执行计划：

[source,sql]
----
SELECT * FROM pg_show_plans;
----

[source,text]
----
  pid  | level | userid | dbid  |                                 plan
-------+-------+--------+-------+-----------------------------------------------------------------------
 11473 |     0 |     10 | 16384 | Function Scan on pg_show_plans  (cost=0.00..10.00 rows=1000 width=56)
 11504 |     0 |     10 | 16384 | Function Scan on print_item  (cost=0.25..10.25 rows=1000 width=524)
 11504 |     1 |     10 | 16384 | Result  (cost=0.00..0.01 rows=1 width=4)
(3 rows)
----

=== 同时查看查询计划与 SQL 语句

使用 `pg_show_plans_q` 视图，可以同时查看查询计划和对应的 SQL 语句。该视图将 `pg_show_plans` 与 `pg_stat_activity` 进行关联：

[source,sql]
----
SELECT * FROM pg_show_plans_q;
----

----
