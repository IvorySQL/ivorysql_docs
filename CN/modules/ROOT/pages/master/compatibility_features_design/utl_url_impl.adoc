= UTL_URL 实现

== 按字节编码

`UTL_URL` 包调用 `contrib/ivorysql_ora/src/builtin_packages/utl_url/utl_url.c` 中的 C 入口。`ESCAPE` 先将输入转为指定编码，再逐字节处理。ASCII 字母、数字和非保留标点会保留。布尔参数控制是否保留分隔符，其余字节各转换为一个使用大写十六进制的 `%XX` 序列。

== 批量解码连续转义

`UNESCAPE` 先收集连续的 `%XX` 序列，再将还原的字节转为数据库编码。一组转义字节可以构成一个多字节字符。字面文本已采用数据库编码，会单独复制。解析器校验每组的两个十六进制数字，并拒绝转义的零字节。

可运行的示例见 xref:master/oracle_compatibility/compat_utl_url.adoc[UTL_URL 包]。
