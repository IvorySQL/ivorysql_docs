= 连接 IvorySQL

IvorySQL 提供 PostgreSQL 模式和 Oracle 兼容模式的连接入口。本指南介绍如何选择端口、使用 `psql` 或其他 PostgreSQL 客户端连接，以及如何排查常见连接问题。安装和启动步骤参见 xref:master/getting-started/quick_start.adoc[快速开始]。

== 连接前准备

确认 IvorySQL 服务已经启动，并准备以下信息：

* 服务器地址：本机连接可使用 `127.0.0.1`；远程连接使用服务器实际可达的地址。
* 端口：根据所需的 SQL 兼容模式选择，见下表。
* 数据库名、具有连接权限的数据库用户，以及该用户所需的认证信息。本文命令以 `ivorysql` 用户和 `ivorysql` 数据库为例；请按实际环境替换。若尚未创建 `ivorysql` 数据库，可先使用现有的 `postgres` 数据库。

[cols="1,2,3",options="header"]
|===
|默认端口 |连接模式 |适用场景

|`5432`
|PostgreSQL 模式
|运行 PostgreSQL 语法的应用，或使用常规 PostgreSQL 客户端。

|`1521`
|Oracle 兼容模式
|需要使用 IvorySQL 所支持的 Oracle 兼容 SQL 语法。连接前确认实例已启用该模式并监听此端口。
|===

端口可以由服务端配置修改，实际连接时应以实例配置为准。`1521` 表示 IvorySQL 的 Oracle 兼容 SQL 入口，不代表可以直接使用 Oracle JDBC 驱动或 SQL*Net 客户端连接。以下两个端口的示例均使用 `psql`。

== 使用 psql 连接

在安装了 `psql` 的客户端上运行以下命令。指定 `-h` 后使用 TCP 连接；`-W` 让 `psql` 交互式提示输入密码，避免将密码写入命令行。如果当前连接使用无需密码的认证方式，可以省略 `-W`。

PostgreSQL 模式：

[source,shell]
----
psql -h 127.0.0.1 -p 5432 -U ivorysql -d ivorysql -W
----

Oracle 兼容模式：

[source,shell]
----
psql -h 127.0.0.1 -p 1521 -U ivorysql -d ivorysql -W
----

连接成功后，可以查看当前会话的模式：

[source,sql]
----
SHOW ivorysql.compatible_mode;
----

结果为 `pg` 或 `oracle`，两个端口的初始模式通常分别为 `pg` 和 `oracle`。在启用 Oracle 兼容的实例中，也可以通过 `SET ivorysql.compatible_mode = oracle;` 切换当前会话的 SQL 模式。使用 `\conninfo` 可查看当前连接，使用 `\q` 退出 `psql`。远程连接时，将 `127.0.0.1` 改为服务器地址，并确认服务端已允许该客户端连接。

== 使用图形工具或应用连接

在支持 PostgreSQL 连接的图形工具中，创建 PostgreSQL 类型的连接并填写以下字段：

[cols="1,3",options="header"]
|===
|字段 |填写内容

|主机
|IvorySQL 服务器地址，例如本机的 `127.0.0.1`。

|端口
|按所需模式填写实际端口，默认分别为 `5432` 和 `1521`。

|数据库
|要连接的现有数据库，例如 `ivorysql` 或 `postgres`。

|用户名、密码
|具有连接权限的数据库用户及其认证信息。

|SSL/TLS
|按服务器的连接安全配置设置。
|===

Java 应用使用 PostgreSQL JDBC 驱动连接 PostgreSQL 模式时，URL 格式如下；将主机、端口和数据库名替换为实际值：

[source,text]
----
jdbc:postgresql://db.example.com:5432/ivorysql
----

使用 Oracle 兼容端口的客户端仍需支持 IvorySQL 提供的 PostgreSQL 连接协议，且应用发出的 SQL 应与该模式兼容。连接前可先用 `psql` 验证目标端口与账号。

== Docker 端口映射

`psql` 从容器外连接时，应使用映射到宿主机的端口。例如，xref:master/getting-started/quick_start.adoc[快速开始]中的 `-p 5434:5432` 将宿主机的 `5434` 映射到容器内的 PostgreSQL 模式端口 `5432`，因此连接命令为：

[source,shell]
----
psql -h 127.0.0.1 -p 5434 -U ivorysql -d ivorysql -W
----

该映射没有发布容器内的 `1521`。若只需从宿主机访问 Oracle 兼容模式，可在创建容器时另行添加 `-p 127.0.0.1:1521:1521`，并检查容器内的服务端监听和认证规则。需要让其他机器访问时，应按最小权限原则选择绑定地址并限制客户端来源；不要直接向不受信任的网络开放端口。宿主机端口若已被占用，可选择其他宿主机端口，并在客户端使用所选端口。

== 远程连接与故障排查

本机可以连接而远程无法连接时，依次检查以下项目：

. *地址和端口*：确认客户端连接的是服务器实际地址和对应模式的端口。若使用 Docker，还须检查宿主机端口映射。
. *监听地址*：`postgresql.conf` 中的 `listen_addresses` 控制 PostgreSQL 模式的监听地址；`ivorysql.conf` 中的 `ivorysql.listen_addresses` 控制 Oracle 兼容模式的监听地址。两者默认仅监听本机。按需配置服务器网卡地址，并重启实例使变更生效。不要仅通过修改一个参数来判断两个端口都已开放。
. *客户端认证*：检查 `pg_hba.conf` 中是否有匹配客户端地址、数据库和用户的 `host` 记录，并使用适合该环境的认证方法。生产环境应限制允许访问的客户端地址范围，避免对所有来源使用 `trust`。修改认证规则后重新加载配置。
. *网络访问*：确认主机防火墙、云安全组及容器网络只向预期客户端开放需要的 TCP 端口。

例如，服务器用于接收连接的网卡地址为 `192.0.2.10` 时，可以在 `postgresql.conf` 中为 PostgreSQL 模式设置：

[source,conf]
----
listen_addresses = '192.0.2.10'
----

如果还需远程访问 Oracle 兼容模式，则在 `ivorysql.conf` 中设置：

[source,conf]
----
ivorysql.listen_addresses = '192.0.2.10'
----

上述地址仅为示例，请使用服务器实际的网卡地址，并在修改后重启实例。

例如，仅允许客户端 `192.0.2.20` 以用户 `ivorysql` 连接数据库 `ivorysql` 时，可在 `pg_hba.conf` 中使用如下规则（示例地址应替换为实际客户端地址）：

[source,conf]
----
host    ivorysql    ivorysql    192.0.2.20/32    scram-sha-256
----

使用该规则前，应确认客户端支持 SCRAM，且用户已设置可用于 SCRAM 认证的密码。`pg_hba.conf` 按顺序匹配规则；如果仍被拒绝，还应检查前面的规则及服务器日志。监听地址的变更需要重启实例，而 `pg_hba.conf` 的变更可以通过重新加载配置生效。
