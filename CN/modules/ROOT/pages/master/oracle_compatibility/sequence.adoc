= 兼容Oracle sequence

== 目的

- 本文档是IvorySQL兼容Oracle sequence文档，目的是可以在IvorySQL中使用Oracle的sequence语句。

== 功能说明

- 序列是一个数据库对象，与表和视图类似，它表示可以由全局数据库命名空间中的任何表和视图使用的整数序列。可以使用NEXTVAL和CURRVAL访问序列值。序列可以是升序或降序

== 测试用例

```
ivorysql=# CREATE sequence seq;
CREATE SEQUENCE
ivorysql=# SELECT seq.NEXTVAL FROM DUAL;
 nextval
---------
       1
(1 row)
ivorysql=# ALTER sequence seq restart start with 10;
ALTER SEQUENCE
ivorysql=# SELECT seq.NEXTVAL FROM DUAL;
 nextval
---------
       10
(1 row)
ivorysql=# DROP SEQUENCE seq;
DROP SEQUENCE
```

== 向标识列导入数据

在 Oracle 模式下，标识列使用关联序列来生成值。根据导入时提供 ID 的方式选择定义子句。

[cols="2,1,1,1",options="header"]
|===
|标识列子句 |省略值或使用 `DEFAULT` |显式指定数字 |字面量 `NULL`
|`GENERATED ALWAYS AS IDENTITY` |生成 |普通 `INSERT` 拒绝 |拒绝
|`GENERATED BY DEFAULT AS IDENTITY` |生成 |保存给定值 |拒绝
|`GENERATED BY DEFAULT ON NULL AS IDENTITY` |生成 |保存给定值 |生成
|===

以下示例导入已有 ID `42`，并将序列的起点设在导入范围之上。两条新记录分别取得 `1000` 和 `1001`。

[source,sql]
----
CREATE TABLE identity_import_demo (
    item_id bigint GENERATED BY DEFAULT ON NULL AS IDENTITY (START WITH 1000)
        PRIMARY KEY,
    label varchar2(30)
);

INSERT INTO identity_import_demo VALUES (42, 'legacy');
INSERT INTO identity_import_demo (label) VALUES ('generated');
INSERT INTO identity_import_demo VALUES (NULL, 'literal null');
SELECT item_id, label FROM identity_import_demo ORDER BY item_id;

DROP TABLE identity_import_demo;
----

插入显式 ID 时，标识列的序列计数保持原值。允许插入自动生成的 ID 前，应根据导入数据设置安全的序列起点，或重新设置序列值。主键或唯一约束负责保证唯一性。
